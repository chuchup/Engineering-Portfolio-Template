# Engineering-Portfolio-Template
Engineering Portfolio Template based on the one I made for myself. Easy to understand and edit for those who are unfamiliar to HTML and CSS but still want an engineering portfolio!

The way it's organized:
index.html --> a welcome page
AllProjects.html --> a catalog of all projects you've ever made, separated into categories
Connect.html --> About you, resume download, other applicable links

Folders:
Style --> contains all .css files (decoration files) and images to be used 
Style >> Assets --> put all photos here, including background photos. Ensure photos are in .jpg and .png format
Projects --> contains all projects you've ever worked on. Feel free to use/edit the template. An example using this template it available.
Resumes --> Put all versions of your resumes here. Ensure that they are in .pdf format
